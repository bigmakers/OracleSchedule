3つの機能が、ひとつに。

🃏

ワンオラクル占い

大アルカナ22枚からカードを1枚引く、シンプルなタロット占い。美しいフリップアニメーションと共に、今日のメッセージを受け取りましょう。

✅

TODO管理

日付指定でタスクを追加。未完了・完了でフィルタリング。さらに、各タスクを個別に占って運勢を確認できるユニークな機能付き。

📔

日記

日々の出来事を記録。写真も添付可能。パスワードロックで大切な日記をしっかり守ります。

📅

カレンダー

月間カレンダーで日付を選択。その日の占い結果とTODOを一覧で確認できます。

🔒

プライバシー保護

日記にパスワードロックを設定可能。アプリがバックグラウンドに行くと自動的にロックされます。

🌏

日本語 / English

設定から表示言語を切り替え可能。日本語と英語に対応しています。
