プライバシーポリシー

最終更新日: 2026年2月23日

「オラクルスケジュール」（以下「本アプリ」）は、ユーザーのプライバシーを最優先に考えて設計されています。本プライバシーポリシーでは、本アプリにおける情報の取り扱いについて説明します。

1. 収集する情報

本アプリは、ユーザーの個人情報を一切収集しません。

本アプリで入力・保存される以下のデータは、すべてお使いのデバイス内にのみ保存されます：

  • タロット占いの結果（カード名、日時、アドバイステキスト）
  • TODO（タスク名、日付、完了状態）
  • 日記（テキスト、写真）
  • 日記のパスワード（デバイスのKeychainに暗号化して保存）
  • 言語設定（日本語/英語の選択）

2. データの送信

本アプリは、ユーザーのデータを外部のサーバー、クラウドサービス、または第三者に送信することは一切ありません。すべてのデータはデバイスのローカルストレージ（SwiftData）およびKeychain内にのみ存在します。

3. 第三者サービス

本アプリは、以下の第三者サービスを使用していません：

  • アクセス解析ツール（Google Analytics等）
  • 広告配信サービス
  • クラッシュレポートサービス
  • ソーシャルメディア連携

4. 写真へのアクセス

日記に写真を添付する機能を利用する場合、本アプリはデバイスの写真ライブラリへのアクセスを求めます。選択された写真はアプリ内のローカルデータベースに保存され、外部に送信されることはありません。写真ライブラリへのアクセスは、ユーザーが明示的に許可した場合にのみ行われます。

5. パスワード保護

日記のパスワードロック機能で設定されたパスワードは、Apple の Keychain（デバイス上の安全な暗号化ストレージ）に保存されます。パスワードは外部に送信されず、デバイスのバックアップにも含まれません（kSecAttrAccessibleWhenUnlockedThisDeviceOnly を使用）。

6. 子供のプライバシー

本アプリは、13歳未満の子供から意図的に個人情報を収集することはありません。本アプリはそもそも個人情報を収集しないため、年齢に関わらず安全にご利用いただけます。

7. データの削除

本アプリのデータを完全に削除するには、デバイスからアプリをアンインストールしてください。これにより、アプリ内に保存されたすべてのデータ（占い履歴、TODO、日記、写真、パスワード設定）が完全に削除されます。

8. プライバシーポリシーの変更

本プライバシーポリシーは、必要に応じて更新される場合があります。重要な変更がある場合は、アプリのアップデート時にお知らせします。最新のプライバシーポリシーは、このページでいつでもご確認いただけます。

9. お問い合わせ

Privacy Policy (English)

Last updated: February 23, 2026

1. Information We Collect

This app does not collect any personal information. All data entered by the user (tarot readings, to-do items, diary entries, photos) is stored exclusively on the user's device and is never transmitted externally.

2. Data Transmission

This app does not transmit any user data to external servers, cloud services, or third parties. All data remains in the device's local storage (SwiftData) and Keychain.

3. Third-Party Services

This app does not use any third-party analytics, advertising, crash reporting, or social media services.

4. Photo Access

When using the diary photo attachment feature, the app requests access to the device's photo library. Selected photos are stored in the app's local database and are never transmitted externally.

5. Password Protection

Diary passwords are stored securely in Apple's Keychain using kSecAttrAccessibleWhenUnlockedThisDeviceOnly. Passwords are never transmitted externally and are not included in device backups.

6. Data Deletion

To completely delete all app data, uninstall the app from your device. This will permanently remove all stored data.

oraclediary.app@gmail.com
